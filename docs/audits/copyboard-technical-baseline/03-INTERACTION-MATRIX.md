# 03 — Interaction Matrix

This matrix records real browser interactions with the existing app, at commit `ac721fe` served locally from a static `python3 -m http.server`. Every row was produced by `evidence/qa-interactions.mjs`. The raw machine-readable output is `evidence/qa-results.json`. This file is generated by `evidence/build-matrix.py`.

## Environment and rules

- **Browser.** Chromium (Playwright 1.56.1, headless). Each scenario runs in a **fresh, isolated browser context** (empty profile) with locale `de-DE` and time zone Europe/Berlin.
- **Viewports.** Desktop 1440×900. Mobile 390×844 (touch + mobile emulation, DPR 2). Tablet 820×1180, screenshots only.
- **Data.** Disposable synthetic data only: generated PNGs, dummy texts, a fake PDF and CSV, and one PIN-locked dummy entry (PIN `1234`, test-only).
- **Network.** All external requests were intercepted:
  - JSZip 3.10.1 was served from a local npm copy.
  - The Supabase client was **replaced by an in-memory mock** for the `I‑C0x` rows, and blocked otherwise.
  - Tesseract was stubbed for I‑43 and blocked otherwise.
  - Fonts were blocked.
  - External hosts requested (all intercepted): `fonts.googleapis.com, cdnjs.cloudflare.com, cdn.jsdelivr.net`. **No request reached `*.supabase.co` or any production resource.**
- **Generated at.** 2026-10-21T10:16:45.943Z. I‑19 was re-run 3× afterwards and reclassified; see its row.
- **Totals.** 58 scenarios: **27 DEFECT**, 22 PASS, 6 OBSERVATION, 3 NOT VERIFIED, 0 BLOCKED.

**Status meaning.**
- PASS: behavior matched the expectation.
- DEFECT: reproduced deviation from the app's own labels, comments or evident intent.
- OBSERVATION: works as coded (or is intermittent and not confirmed), but noteworthy for the refresh.
- NOT VERIFIED: requires capabilities that were unavailable.

**Severity.**
- Critical: data loss without user action.
- High: data loss, security impact, or a core flow broken.
- Medium: functional defect with a workaround.
- Low: cosmetic or edge case.

**Synthetic events.** Paste is dispatched as a `ClipboardEvent`; touch uses CDP emulation. They are close to, but not identical with, real user input. Where this matters, the row's note says so.

Reproduce:

```bash
python3 -m http.server 8765 --bind 127.0.0.1   # repo root
PLAYWRIGHT_PATH=<path to playwright> JSZIP_PATH=<path to jszip.min.js> \
  node docs/audits/copyboard-technical-baseline/evidence/qa-interactions.mjs [id-regex]
```
